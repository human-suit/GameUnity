# Plague — элита (Sector B)

## Идентичность

| | |
|---|---|
| **Имя в UI** | Plague / Чума |
| **Тип** | Elite enemy |
| **Сектор** | B — Болото |
| **Роль** | Учит игрока работать с **ядом** до unstable rule «Яд питается» |

## Визуал (Fear & Hunger pixel)

- Сгорбленный **бывший житель** деревни — не монстр-мутант, а **носитель**
- Кожа **зеленовато-серая**, пятна, вздутые вены на шее
- **Тряпичная маска** на рот (пропитана слизью), один глаз закрыт повязкой
- Рваный плащ/накидка из мешковины, **капает** с рукавов (яд, не кровь)
- Ходит **шаркая**, плечи вперёд, кашляет в ACTION
- Палитра: `#6B7A62` кожа, `#3D4A38` тени, `#8FA86E` яд/слизь, `#5C5048` ткань, `#2E2A26` фон

## Silhouette

Средний, **шире Subject 07**, **уже Butcher**. Голова вперёд + маска = узнаваемый силуэт на карте.

## Анимации (sprite sheet)

| Row | Назначение |
|-----|------------|
| TURN | front / back |
| IDLE | 6 — дрожь, слизь капает |
| WALK | 8 — медленный shuffle |
| ACTION | 4 — кашель / «выдыхает» ядовитый пар |
| STAGGER | 3 |
| DEATH | 6 — падает, лужа зелёной слизи |
| EXPRESSIONS | Hostile, Cough, Rage, Weak (для intent UI) |
| BODY PARTS | head, mask, torso, arms, legs, drip blob |

## Лор (1 абзац)

Житель Sector A, которого «перевели» в болото раньше вас. Протокол записал: **устойчив к токсину, заразен для других**. Он не охотится — стоит на пути к exit и кашляет, пока вы не упадёте или не пройдёте мимо (если добавим stealth позже).
