# Sector C — Двор

## Назначение

~4 мин + **boss**. Unstable Rule #2: **«Карты лгут»**.

## Unstable Rule

1 случайная карта в руке каждый бой: **иконка та же, эффект другой** (показывается после розыгрыша).

## Размер

~**35×25** tiles. Забор, тележки, кучи мусора.

## Layout

```
[ забор ] [ тележка ] [ Subject 03 ]
              |
         [ Patchwork Butcher @ EXIT ]
              |
    [ финальные ворота ] → Ending
```

## Контент

| Элемент | Детали |
|---------|--------|
| Pre-boss | 1–2 × Subject 03 |
| Boss | **Patchwork Butcher** блокирует exit |
| Endings | A: прошёл ворота / B: остался (game over flavor) |

## Атмосфера

Красный tint неба, прожектор на боссе, табличка: *«Sector C — disposal»*.
