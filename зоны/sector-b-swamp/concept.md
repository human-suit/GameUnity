# Sector B — Болото

## Назначение

~4 мин. Ввод **яда** и **Unstable Rule #1**.

## Unstable Rule

**«Яд питается»** — +1 Poison игроку в **начале каждого боя**.

## Размер

~**45×28** тiles. Больше открытого пространства, меньше зданий.

## Layout

```
[ туман край ] ~~~~ болото ~~~~ [ Plague элита на main path ]
                      |
                 [ rest: костёр ]  (heal 15 HP, 1 раз)
                      |
                 [ EXIT мост ]
```

## Контент

| Элемент | Детали |
|---------|--------|
| Common | 2 × Subject 03 (грязнее tint) |
| Elite | **Plague** — main path |
| Optional | **Subject 12** — side path, drop Antidote |
| Rest | 1 костёр mid-map |
| Event | **туман** (видимость ↓) ИЛИ **сдвиг** (1 проход закрыт/открыт) |

## Атмосфера

Зелёный tint, пузыри, доски через болото.
