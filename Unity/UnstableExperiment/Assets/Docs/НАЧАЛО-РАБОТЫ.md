## Что это за проект

2D horror demo **~10–15 мин**. Subject 07 проходит 3 сектора (Деревня → Болото → Двор).

| Система | Суть |
|---------|------|
| **Overworld** | Top-down комнаты, WASD, двери на краях |
| **Route Map** | Карта как STS — только планирование, переход через дверь |
| **Combat** | Lottery protocol chits (не колода STS) |
| **UNSTABLE** | Правила ломаются каждый сектор |

## Промпт / ТЗ для разработки игры (Unity)

Использовать **`КОНЦЕПЦИЯ-ИГРЫ.md`** §5–§13 как ТЗ:

```
1. Bootstrap → load room by rooms_graph.json currentRoomId
2. Room: tilemap 32px PPU, collision, 4-dir movement Subject 07
3. Door trigger → check key → load targetRoom, spawn at entry door
4. Aggro → overlay lottery combat (tickets.json + unstable_rules.json)
5. sector_map_a item → unlock Route Map UI (read-only, Tab)
6. Sector transition at a_gate / b_bridge → apply sector rules
```

**Данные:** `игра/data/rooms_graph.json` — единственный source of truth для level graph.

**Стартовая комната:** `a_plaza` → art `игра/rooms/sector-a/a_plaza_room.png`.
