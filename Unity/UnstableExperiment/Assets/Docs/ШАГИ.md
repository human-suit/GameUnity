# Пошаговая сборка в Unity (вручную)

Все шаги — только через Hierarchy и Inspector. **Никаких меню-автоматов.**

---

## Шаг 1 — Площадь + WASD ✅ (уже сделано)

У тебя уже есть: **Grid**, **Walk**, **Player**, **Main Camera**.

Проверка: **Ctrl+S** → **Play ▶** → WASD.

---

## Шаг 2 — Туман вокруг героя

1. Hierarchy → **Main Camera**
2. **Add Component** → `Vision Fog`
3. Настрой:
   - **Inner Radius** `8–12`
   - **Outer Radius** `15–20`
   - **Falloff Power** `2.5`
   - **Fog Color** — чёрный, Alpha = 1
4. **Ctrl+S** → **Play ▶**

---

## Шаг 3 — Двери и комнаты (делаешь сам)

### A. Создай GameRoot

1. Hierarchy → ПКМ → **Create Empty** → назови **`GameRoot`**
2. **Add Component** → **`Room Manager`**
3. В Inspector у **Room Manager**:
   - **Room Background** → перетащи **`Grid`**
   - **Player** → перетащи **`Player`**

### B. Дочерние объекты

1. ПКМ на **GameRoot** → **Create Empty** → **`Doors`**
2. ПКМ на **GameRoot** → **Create Empty** → **`Loot`**
3. В **Room Manager**:
   - **Doors Root** → **`Doors`**
   - **Loot Root** → **`Loot`**

### C. HUD и взаимодействие

1. **GameRoot** → **Add Component** → **`Game HUD`**
2. **Player** → **Add Component** → **`Player Interact`**

### D. Координаты дверей на карте

1. В **Scene** поставь **Player** туда, где он спавнится на площади
2. Запомни **Position** (например X=-7, Y=-1) → в **Room Manager** поле **Spawn Point**
3. Найди на tilemap **4 выхода** (проходы в стене):
   - **Door North** — север (колодец)
   - **Door South** — юг (дом)
   - **Door East** — восток (переулок)
   - **Door West** — запад (ворота)
4. Для каждого выхода: создай пустой объект в Scene, поставь в центр прохода, скопируй **Position** в поля Room Manager

**Подсказка:** включи **2D** вид, приблизься к краю карты — координаты смотри в Inspector у временного объекта.

### E. Стартовая комната

Скрипт `GameState` при старте читает `a_plaza`. Ничего менять не нужно, если JSON не трогал.

### F. Проверка

1. **Ctrl+S** → **Play ▶**
2. Слева вверху: **Комната: Площадь**
3. Иди к краю карты → появится **`[E] Дом`** (или другая дверь)
4. **E** — переход
5. **Дом** (юг) → подбери ключ и карту (**E**)
6. **Ворота** (запад) — нужен `rust_key`

Данные комнат: `Assets/Resources/Data/rooms_graph.json`

## Шпаргалка

| Задача | Где |
|--------|-----|
| Двери / комнаты | GameRoot → Room Manager |
| Координаты дверей | Room Manager → Door North/South/East/West |
| Туман | Main Camera → Vision Fog |
| Скорость ходьбы | Player → Player Move → Speed |
| Коллайдеры стен | Grid → Collision (Tilemap Collider + Composite) |

## Важно

- После каждого шага: **Ctrl+S** → **Play ▶**
- Смотри вкладку **Game**, не Scene
- Изменения в Play **не сохраняются** — всегда Stop → правь → Save
