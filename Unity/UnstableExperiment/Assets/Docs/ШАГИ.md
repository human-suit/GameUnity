## Шаг 2 — Туман вокруг героя

Чтобы **не всю карту** было видно — круг света вокруг персонажа.

### Быстро (одна кнопка)

1. **Unstable Experiment** → **Шаг 2 — Туман вокруг героя**
2. **Ctrl+S** → **Play ▶**

### Настроить радиус

1. Hierarchy → **Main Camera**
2. Inspector → компонент **Vision Fog**
3. Меняй:
   - **Inner Radius** `1.6` — яркий круг у ног
   - **Outer Radius** `3.2` — где уже чёрная темнота
   - **Falloff Power** `2.5` — резкость (как F&H)
   - **Fog Color** — чёрный, Alpha = 1

## Шаг 3 — Свой персонаж (заменить спрайт)

### A. Подготовь PNG

- **Прозрачный фон** (не чёрный квадрат!)
- В Photoshop / GIMP / Aseprite: удали фон → сохрани **PNG**
- Персонаж смотрит вниз или вбок — как тебе нужно

### B. Закинь в Unity

1. Скопируй файл в:  
   `Assets/Resources/Art/Characters/`  
   например: `subject_07_walk.png`
2. В Unity кликни на PNG в Project
3. **Inspector** справа:
   - **Texture Type** → `Sprite (2D and UI)`
   - **Sprite Mode** → `Single` (один кадр) или `Multiple` (анимация)
   - ✅ **Alpha Is Transparency**
   - **Pixels Per Unit** → `100` (или как у остальных)
   - Нажми **Apply**

### C. Убрать чёрный фон (если остался)

1. Кликни PNG → Inspector
2. ✅ **Alpha Is Transparency** → Apply
3. Если фон всё ещё чёрный — проблема в **самом файле**:  
   открой в редакторе и сделай фон прозрачным, сохрани заново

### D. Поставить на Player

**Вариант 1 — один спрайт (без анимации):**

1. Hierarchy → **Player**
2. Inspector → **Sprite Renderer** → поле **Sprite**
3. Перетащи свой PNG (или ▼ выбери из списка)
4. Подгони размер: меняй **Scale** у Player (например `2, 2, 1`)

**Вариант 2 — не трогать сцену, заменить файл:**

1. Замени `subject_07_icon.png` своим файлом (то же имя)
2. Unity перезагрузит автоматически

## Шаг 4 — Анимация ходьбы (когда готов sprite sheet)

### 1. Нарезать кадры

1. PNG с несколькими кадрами → Inspector → **Sprite Mode: Multiple** → Apply
2. **Sprite Editor** → **Slice** → Grid By Cell Count или Automatic
3. **Apply**

### 2. Animator

1. Hierarchy → **Player** → **Add Component** → **Animator**
2. Project → ПКМ → **Create** → **Animator Controller** → назови `Subject07`
3. Перетащи Controller в поле **Controller** у Animator на Player

### 3. Анимации

1. Window → **Animation** → **Animation**
2. Выбери **Player** → **Create** → `idle.anim`
3. Добавь кадры: кнопка **Add Property** → Sprite Renderer → Sprite  
   или перетаскивай кадры на timeline
4. То же для `walk_down`, `walk_up`, `walk_side` и т.д.

### 4. Связать с движением (позже)

Когда анимации готовы — напиши, добавим простой скрипт  
«если жмёшь W → walk_up, S → walk_down…»

## Шпаргалка

| Задача | Где |
|--------|-----|
| Заменить картинку персонажа | Player → Sprite Renderer → Sprite |
| Размер персонажа | Player → Transform → Scale |

## Важно

- После каждого изменения: **Ctrl+S** → **Play ▶**
- Смотри вкладку **Game**, не Scene
- Чёрный квадрат у персонажа = **нет прозрачности в PNG**, правь файл, не Unity
