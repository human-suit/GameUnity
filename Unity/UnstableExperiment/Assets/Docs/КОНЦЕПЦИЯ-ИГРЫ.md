# Unstable Experiment — концепция игры (master)

> **Назначение файла:** единый источник правды для промптов, level design и Unity.  
> Связанные документы: `GDD-кратко.md` · `ui-карты/lottery-combat.md` · `зоны/sector-*/concept.md` · `окружение/ENVIRONMENT-v1.md`

---

## 1. Pitch

**Unstable Experiment** — короткий 2D horror run (~10–15 мин).  
Игрок — **Subject 07**, подопытный объекта эксперимента. Он **ходит по комнатам** (вверх/вниз/влево/вправо), встречает патрули, дерётся **lottery-боями** (protocol chits, не STS-колода), находит **карту маршрута** и по ней планирует путь — но **переходит между локациями только через двери** в конце/краю комнаты.

Три сектора: **Деревня → Болото → Двор**. Правила мира и билетов ломаются каждый сектор (UNSTABLE).

---

## 2. Два слоя навигации

| Слой | Что видит игрок | Аналог |
|------|-----------------|--------|
| **Комната (Overworld)** | Top-down поле, WASD, враги, предметы, **двери на краях** | Классическая бродилка / Zelda room |
| **Карта маршрута (Route Map)** | Схема узлов и связей, куда ведут двери, что пройдено | Slay the Spire map — **только планирование** |

### Главное отличие от STS

| Slay the Spire | Unstable Experiment |
|----------------|---------------------|
| Клик по узлу → сразу событие/бой | Клик по узлу на карте → **подсказка**, куда идти |
| Абстрактная карта = весь геймплей | Карта = **надстройка**; реальный переход = **физически зайти в дверь** |
| Одна «линейка» комнат | **Отдельная tilemap на каждую комнату**, связь через `door_id` |

### Главное отличие от «одной большой карты»

| Большой open map (старое GDD) | Новая модель |
|-------------------------------|--------------|
| 40×30 тайлов на весь сектор | **5–8 комнат** на сектор, каждая 12×10 … 20×15 тайлов |
| Exit в far corner | Exit = **дверь** из hub-комнаты или финальной комнаты |
| Ключ на карте | Ключ в **комнате-доме** → открывает **конкретную дверь** на карте маршрута |

## 3. Core loop (одна сессия)

```
1. Старт: комната «Деревня — площадь» (hub)
2. Обучение: ходьба, aggro, первый lottery-бой
3. Находка: «Карта сектора A» → открывается Route Map (Tab / кнопка MAP)
4. Игрок смотрит карту → видит: Дом с ключом · Колодец · Магазин? · Ворота EXIT
5. Идёт к нужной двери на краю комнаты → [E] Enter → fade → новая комната
6. В доме: ключ → на Route Map дверь «Ворота» меняет статус locked → open
7. Через ворота → следующий сектор (новый hub + новая карта)
8. Сектор C → босс у финальной двери → ending
```

**Бой:** только при aggro (контакт с патрулем или триггер в комнате).  
**Route Map:** не телепорт; показывает граф, легенду дверей, locked/unvisited/cleared.

## 4. Термины (для промптов и кода)

| Термин | EN (код) | Описание |
|--------|----------|----------|
| Комната | `Room` | Отдельная walkable-сцена с коллизией и spawn-точками |
| Дверь | `Door` | Trigger на краю комнаты; ведёт в другую `Room` |
| Узел карты | `MapNode` | Визуальный узел на Route Map; 1:1 с комнатой или группой |
| Ребро | `MapEdge` | Связь «эта дверь ведёт сюда» |
| Hub | `hub` | Центральная комната сектора (обычно старт) |
| Сектор | `Sector` | A / B / C — свой набор комнат + unstable rules |
| Карта сектора | `SectorMap` | Предмет/UI; разблокирует Route Map для сектора |

## 5. Физический слой (комната)

### Управление

| Input | Действие |
|-------|----------|
| WASD / стрелки | Движение 4 направления |
| Shift (opt) | Не бег — медленный horror pace |
| E / Enter | Войти в дверь (если в зоне и не locked) |
| Tab / M | Route Map (если найдена карта сектора) |
| Esc | Пауза |

### Техника

| Параметр | Значение |
|----------|----------|
| Tile size | **32×32** px (PPU 32) |
| Камера | Follow Subject 07, лёгкий vignette |
| Коллизия | Стены, дома, забор — блок; двери — trigger |
| Враг | Patrol AI внутри комнаты; aggro radius → lottery combat |
| Стиль | F&H hand-drawn props (`окружение/sector-*/topdown_*`) |

### Размер комнаты (ориентир)

| Тип | Тайлы | Пример |
|-----|-------|--------|
| Малая | 12×10 | дом внутри, сарай |
| Средняя | 18×14 | площадь, магазин |
| Большая | 24×18 | hub деревни, открытое болото |
| Коридор | 6×20 | связка между двумя hub (редко) |

### Двери — правила размещения

- **1–4 двери** на комнату, только на **краях** (north/south/east/west wall).
- У каждой двери: **вывеска** или иконка (SHOP / HOME / EXIT / SWAMP).
- Закрытая дверь: visual locked + на Route Map серый узел.
- После ключа/ивента: `DoorState` → `Open`, анимация замка.

```
        [ DOOR: Home ]
              |
    +---------+---------+
    |                   |
[D: Well]   PLAZA    [D: Gate LOCKED]
    |                   |
    +---------+---------+
              |
        [ DOOR: Alley ]
```

Игрок spawn у нижней двери при входе **с противоположной стороны** (вошёл с south → spawn south interior).

## 6. Route Map (карта как в STS, но без телепорта)

### Когда открывается

- **Sector A:** находка в комнате «Дом с картой» или сундук на площади после tutorial-боя.
- **Sector B/C:** автоматически при входе в сектор (новый лист протокола) или находка в hub.

### Что показывает

- Узлы = комнаты сектора (иконка типа: бой / rest / shop / event / boss / exit).
- Рёбра = какие двери соединяют (подпись: «North door from Plaza»).
- Статусы: `???` (не visited) · `visited` · `cleared` (бой выигран / loot взять) · `locked` · `current`.
- **Текущая комната** подсвечена; клик по другому узлу → **tooltip**: «Иди к восточной двери на площади».

### Чего карта НЕ делает

- Не телепортирует.
- Не запускает бой без входа в комнату.
- Не заменяет exploration — только **ориентир** и fantasy «протокольный план объекта».

### Визуал карты (промпт)

- Грязная бумага / термоплан, штамп **FACILITY ROUTE A**.
- Узлы — круги с пиктограммами (череп = бой, кровать = rest, ? = event).
- Линии — пунктир, как в STS, но **desaturated**, кровь только на boss-node.
- Sector B: зелёные пятна на бумаге; Sector C: красный штамп DISPOSAL.

## 7. Типы комнат

| type | id | Содержимое | Двери |
|------|-----|------------|-------|
| Hub | `hub` | Старт сектора, 0–1 патруль, табличка сектора | 2–4 исхода |
| Combat | `combat` | 1–2 врага, узкий лут | 1 вход + 1 выход |
| Elite | `elite` | мини-босс / элита | 1–2 |
| Shop | `shop` | NPC «Dispenser» — 1 consumable, 1 ticket pack (no gold — **обмен HP** или «протокол») | 1 |
| Rest | `rest` | heal 15 HP, 1 раз (костёр / койка) | 1–2 |
| Event | `event` | текст + выбор (туман, сдвиг двери) | 1–2 |
| Key | `key` | fetch: ключ, antidote, карта | 1 |
| Boss | `boss` | финальный враг блокирует exit-door | 1 вход |
| Transition | `transition` | короткая комната-ворота в следующий сектор | 2 |

## 8. Демо-run — граф Sector A (Деревня)

**Unstable:** нет (tutorial).  
**Цель:** ключ → открыть ворота → Sector B.

### Route Map (узлы)

```
                    [Well — event?]
                          |
    [Home+Key] —— [PLAZA hub] —— [Alley — combat x2]
                          |
                    [Gate — EXIT]
                          |
                     (Sector B)
```

### Комнаты (детально)

| room_id | type | tilemap theme | Двери |
|---------|------|---------------|-------|
| `a_plaza` | hub | grass, road, sign SECTOR A | N→well, E→alley, S→home, W→gate(locked) |
| `a_home` | key | interior wood | S→plaza; loot: **Sector Map A**, optional consumable |
| `a_well` | event | cobble + well | S→plaza; event: «пусто» / +1 ticket pack |
| `a_alley` | combat | narrow dirt | W→plaza; 2× Subject 03 patrol |
| `a_gate` | transition | gate, fence | E→plaza; needs **Rust Key**; exit→Sector B hub |

### Tutorial beats в Sector A

1. `a_plaza`: движение, табличка baseline.
2. Первый aggro (1× Subject 03): lottery combat, reveal исходов A/B/C.
3. `a_home`: взять **Карту A** + **Rust Key**.
4. Route Map: игрок видит, что Gate был locked → now open.
5. `a_gate`: fade, голос *«Sector B. Toxin parameters changed.»*

## 12. Unity — архитектура (минимум)

```
Scenes/
  Bootstrap.unity
  RoomLoader.unity          # additive load room prefab
Prefabs/
  Rooms/ a_plaza, a_home, ...
  Actors/ subject_07, subject_03, ...
  UI/ RouteMapCanvas, CombatOverlay, DoorPrompt
ScriptableObjects/
  RoomDef.asset             # id, sector, type, doors[], spawn
  SectorMapDef.asset        # nodes[], edges[], unlock item
  DoorLink.asset            # door_id, target_room, required_key
Data/
  rooms_graph.json          # см. §13
```

**Flow:** `GameState.currentRoomId` → load tilemap → spawn player at `door_entry_id`.  
**Door interact:** check `DoorLink.requiredKey` → load target room.  
**Route Map:** read-only view of `SectorMapDef`, highlight `currentRoomId`.
