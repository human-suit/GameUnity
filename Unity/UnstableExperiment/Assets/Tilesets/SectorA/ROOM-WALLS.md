# Room Walls — Sector A

Файлы:
- `room_walls_sector_a_sheet.png` — фронт + углы
- `room_walls_sector_a_profile_sheet.png` — **стены в профиль** (боком)

Сетка обоих: **8 × 4**, ячейка **64×64**.

Стиль: как `topdown_sector_a_sheet` — камень, кирпич, забор, F&H.

---

## Profile sheet (боком / в профиль)

| Ряд | Куда на комнате |
|-----|-----------------|
| 1 | **Север** — профиль вверх |
| 2 | **Юг** — профиль вниз (толще) |
| 3 | **Запад** — стена слева, 8 вариантов |
| 4 | **Восток** — стена справа, 8 вариантов |

Импорт и Slice **так же** (8×4, PPU 64).  
Добавь тайлы во **вторую палитру** `SectorA_Walls_Profile` или в ту же.

Поворот **`[` / `]`** в Palette — если нужно дожать угол.

---

Вид сверху, игрок внутри:

```
[ угол ] [ север ×N ] [ угол ]
[ запад×M ]   ПОЛ (Ground)   [ восток×M ]
[ угол ] [  юг ×N  ] [ угол ]
```

| Часть комнаты | Ряд в sheet | Какие тайлы (0–7 слева направо) |
|---------------|-------------|----------------------------------|
| **Север** (верх) | **1-й ряд** | камень, кирпич, забор… — чередуй |
| **Юг** (низ, «лицо» стены) | **2-й ряд** | окно, кирпич, разрушенная… |
| **Запад** (лево) | **3-й ряд** | клетки **0–3** |
| **Восток** (право) | **3-й ряд** | клетки **4–7** |
| **Углы** | **4-й ряд** | 0–3 внешние углы, 4–7 внутренние |

Дверь в стене: пропуск 1–2 клетки на **Walls**, потом объект **door** из основного sheet.

---

## Unity — быстро

1. Import `room_walls_sector_a_sheet.png`
   - **Sprite Mode: Multiple**
   - **Pixels Per Unit: 64**
   - **Filter: Point**
2. **Sprite Editor → Slice → Grid 8 columns, 4 rows**
3. Перетащи тайлы в **Tile Palette** `SectorA_Walls`
4. Рисуй на слое **Walls** (кисть **B**)
5. **Tilemap Collider 2D** + **Composite** на Walls (см. ШАГИ.md)

---

## Вариативность

На одной стороне комнаты чередуй 2–3 разных тайла одного ряда — будет «живее», но стиль один.

Фон magenta — **не обрабатывать** скриптом персонажей; в Unity **Alpha Is Transparency** или удали magenta в GIMP (Color to Alpha).
