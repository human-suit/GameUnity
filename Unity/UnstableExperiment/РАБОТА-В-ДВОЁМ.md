# Работа вдвоём над Unity-проектом (Game Jam)

> Репозиторий: https://github.com/human-suit/GameUnity  
> Unity-проект: **`Unity/UnstableExperiment/`**

---

## 1. Первый запуск на новом компьютере

### Что установить

1. **Git** — https://git-scm.com/downloads  
2. **Unity Hub** — https://unity.com/download  
3. В Hub установи **Unity 2022.3.20f1** (LTS) — та же версия, что у напарника!

### Скачать проект

```bash
git clone https://github.com/human-suit/GameUnity.git
cd GameUnity
```

### Открыть в Unity

1. Unity Hub → **Open** → выбери папку  
   `GameUnity/Unity/UnstableExperiment`
2. Подожди **первый импорт** (5–15 мин) — Unity сам создаст `Library/` локально  
3. Открой сцену: `Assets/Scenes/Main.unity`
4. Меню **Unstable Experiment → Шаг 1 — Площадь и персонаж** (если сцена пустая)
5. **Play ▶** — проверь что работает

> **`Library/` и `Temp/` в Git нет** — это нормально. Unity создаёт их у каждого на своём ПК.

## 2. Ежедневный workflow (оба разработчика)

```
Утро:  git pull origin main     ← забрать изменения напарника
       открыть Unity, дождаться компиляции
Работа: делаете задачи, Ctrl+S в Unity
Вечер: git add → commit → push  ← отдать изменения
```

### Команды (копируй)

```bash
cd GameUnity

# Перед работой — ВСЕГДА
git pull origin main

# После работы
git status
git add Unity/UnstableExperiment/
git commit -m "описание что сделал"
git push origin main
```

## 3. Кто что делает (Game Jam)

| Ты (код / Unity) | Напарник (арт / level) |
|------------------|------------------------|
| Скрипты в `Assets/Scripts/` | PNG в `Assets/Resources/Art/` |
| Сцены `Assets/Scenes/` | Спрайты персонажей, комнат |
| Animator, коллайдеры | Прозрачный фон у PNG |
| Меню **Unstable Experiment** | `rooms_graph.json` (дизайн комнат) |

**Правило:** не редактируйте **одну и ту же сцену** одновременно без sync.  
Лучше: один делает `Main.unity`, другой — арт в отдельных PNG.

## 4. Unity-версия — ОБЯЗАТЕЛЬНО одинаковая

Файл: `ProjectSettings/ProjectVersion.txt` → **2022.3.20f1**

Если версии разные → Unity пересохранит все файлы → **конфликты в Git**.

## 5. Что коммитить в Git

| ✅ Коммитим | ❌ НЕ коммитим |
|------------|---------------|
| `Assets/` (спрайты, сцены, скрипты) | `Library/` |
| `ProjectSettings/` | `Temp/` |
| `Packages/manifest.json` | `Logs/` |
| `*.meta` файлы рядом с ассетами | `UserSettings/` |
| `README.md`, `ШАГИ.md` | `.csproj`, `.sln` |

> **`.meta` файлы важны!** Без них у напарника сломаются ссылки на спрайты.

## 6. Ветки (рекомендуем для джема)

```bash
# Создать ветку под задачу
git checkout -b feature/player-anim

# Работаешь, коммитишь...
git push -u origin feature/player-anim

# На GitHub → Pull Request → merge в main
# Или локально:
git checkout main
git pull origin main
git merge feature/player-anim
git push origin main
```

Для джема можно и **прямо в main**, но **всегда `git pull` перед работой**.

---

## 7. Конфликты — что делать

### Если `git pull` ругается

```bash
git stash
git pull origin main
git stash pop
```

### Если конфликт в `.unity` или `.prefab`

1. Не паникуй
2. Скажи напарнику в чат — кто последний менял сцену
3. Один откатывает свои изменения в сцене, другой пушит
4. Потом второй заново вносит правки

**Профилактика:** работайте в разных файлах; сцены сохраняйте по очереди.

## 8. Структура Unity-проекта

```
Unity/UnstableExperiment/
  Assets/
    Scenes/Main.unity       ← главная сцена
    Scripts/                  ← код (PlayerMove, VisionFog…)
    Editor/                   ← меню Unstable Experiment
    Resources/Art/            ← спрайты (комнаты, герои)
    Resources/Data/           ← JSON (комнаты, бой)
    Docs/ШАГИ.md              ← пошаговая инструкция
  ProjectSettings/            ← настройки Unity (в Git!)
  Packages/manifest.json      ← пакеты Unity (в Git!)
```
