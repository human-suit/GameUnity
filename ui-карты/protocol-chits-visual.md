# Protocol Chits — визуал билетов (v2)

> Механика та же (`lottery-combat.md`). Меняется **только** облик.

## Концепт: не лотерея, а **талон протокола**

Билет = **отрывной чек эксперимента**, не scratch-card из киоска.

| Было (v1) | Стало (v2) |
|-----------|------------|
| Яркие вертикальные полоски | **Сепия / грязная термобумага** |
| Круги с `?` | **Три окна с чёрной цензурой** `[███]` + метки α β γ |
| SCRATCH | **REDEEM** (погасить талон) |
| Молния = energy | **Три укола-точки** ●●○ = cost |
| PROTOCOL RED | Штамп **LOT-R** / AGGRESSIVE |
| Barcode снизу | Серийник `07-XXXX` + «VOID IF TAMPERED» |

## 6 типов — штампы (data id не меняется)

| id | Штамп | Цвет чернила |
|----|-------|--------------|
| red | LOT-R · AGGRESSIVE | бордовый |
| blue | LOT-B · DEFENSIVE | синий |
| green | LOT-G · PURGE | зелёный |
| yellow | LOT-Y · STABILIZE | жёлтый |
| wild | LOT-? · ANOMALY | фиолетовый |
| blank | LOT-0 · NULL | серый |

## Layout 128×192

```
╔══ torn edge ══════════════╗
║ FACILITY [X]  07-0041     ║
║ ┌─α─┐ ┌─β─┐ ┌─γ─┐        ║
║ │███│ │███│ │███│  ← censored
║ └───┘ └───┘ └───┘        ║
║ [AGGRESSIVE]  cost ●●○   ║
║ ─── barcode ───          ║
║      [ REDEEM ]          ║
╚══════════════════════════╝
```

## Scratch-анимация

Не «стираем круг» — **снимаем полоску цензуры** (3 кадра: бар → царапина → иконка исхода).

## UNSTABLE UI

- **FORGED:** штамп «SPECIMEN MISMATCH» (не PROTOCOL MISMATCH)
- Ложный тип: другой цвет чернил штампа, roll по реальному id
